# マインドマップツール

ゲームシナリオ企画用マインドマップ作成ツール。要件定義書（`マインドマップツール_要件定義書.md`）に基づいて実装。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開く。ビルドは `npm run build`。

### 同期機能について

要件定義書ではFirebase（Firestore + 匿名認証）による複数PC間同期が想定されていますが、これには利用者自身のFirebaseプロジェクト作成・APIキー発行が必要なため、本実装には含めていません。

現状は各PCのブラウザの IndexedDB にローカル保存されます（同一ブラウザでは再訪問時も自動的にデータが残ります）。プロジェクトごとに同期コードは発行・表示されますが、他デバイスとの実際のデータ連携はまだ行われません。

今後Firebase連携を追加する場合の設計メモ：
- データ構造は要件定義書5章の`projects/{projectId}/nodes/{nodeId}`・`edges/{edgeId}`のサブコレクション構成にすでに合わせてあります（`src/types.ts`の`NodeRecord`/`EdgeRecord`、`src/repo/projectsRepo.ts`）。
- `src/store/mapStore.ts`のデバウンス保存処理（`scheduleSave`）を、IndexedDB書き込みに加えてFirestore書き込みも行うよう差し替えれば移行しやすい構成にしています。
- Firebase導入時は `firebase` パッケージを追加し、匿名認証＋同期コードでのプロジェクト共有ロジックを`projectsRepo.ts`に追加してください。

## 技術スタック

- React + TypeScript + Vite
- React Flow（`@xyflow/react`）
- Zustand（状態管理）
- Dexie（IndexedDBラッパー、ローカル保存）
- html-to-image（PNG/SVGエクスポート）

## 使い方のヒント

- ノードはダブルクリックでテキスト編集
- ノードの枠の任意の辺（上下左右）からドラッグすると矢印を作成できます
- 矢印上のラベルをクリックすると「問い」を設定・変更できます
- 左サイドバーの「問いライブラリ」でオリジナルの問いを管理できます
- ヘッダーの「まとめを出力」から企画書のたたき台となるテキストを生成・コピーできます
